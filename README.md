# Xingyuan Zeng

Source for [zxyangyu.github.io](https://zxyangyu.github.io/), a lightweight academic homepage with research interests, publications, projects, and contact links.

The production site lives in [`docs/`](docs/). A GitHub Actions workflow publishes that directory to the `gh-pages` branch whenever it changes.

The older al-folio template remains in the repository for history, but it is no longer part of the production build.
