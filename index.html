01 / Research

Building systems that find the right context and use it well.

My work focuses on reliable access to external knowledge: how to structure it, retrieve it for a specific question, and preserve useful experience across extended interactions.

  • Retrieval-augmented generation

    Graph-aware and query-adaptive methods for grounding language models.

  • Agent memory

    Reusable representations that support long-horizon reasoning.

  • Tool-augmented agents

    Agents that coordinate tools and evidence across real systems.

  • Computer vision

    Datasets and evaluation for challenging visual domains.
